# 고등학생이었던 내가 이세계에서는 사회인?

(저장소·코드 이름은 그대로 isekai3d. 2026-10-20 에 «이세계 3D» 에서 이 제목으로 바뀌었어요.)

이세계 2D(`../dwellers`)의 게임 규칙을 그대로 쓰는 3D 버전이에요. 부지를 three.js로 그리고, 캐릭터는 VRoid 캐릭터나 도형 캐릭터로 보여 줘요. 2D 버전은 따로 유지해요.

- 실행: `npm install` 후 `npm run dev` → http://localhost:5410
- 확인 명령: `npx vitest run`, `npx tsc --noEmit`, `npm run build`
- 3D 동작 확인: 시작 화면의 **🧪 동작 실험실**에서 욕구가 줄지 않는 집(또는 집 다섯 곳, 근무지 119곳)의 가구마다 캐릭터 동작을 하나씩 해 볼 수 있어요.
- 3D 에셋 확인: 시작 화면의 **🧩 에셋 갤러리**에서 모든 가구를 사람 옆에 놓고 돌려 볼 수 있어요.
- 옷·헤어 확인: 시작 화면의 **👗 옷장**에서 헤어와 옷을 바꿔 입히고 피팅룸에서 갈아입는 모습을 봐요.
- 티셔츠 디자인 (개발 모드 전용): **캐릭터 만들기 → 옷차림 → 골라 입기 → 티셔츠** 또는 게임 중 **이름·외모 바꾸기 / 옷장**에서 프린트 스튜디오를 사용해요. PNG/JPG(8MB 이하)를 불러오거나 OFF DUTY 샘플로 시작해 앞·뒤, 위치, 크기, 회전, 바탕색을 조절해요. 그림은 최대 512픽셀로 저장되어 캐릭터의 게임 저장에 포함돼요. 현재 프린트는 티셔츠에만 표시되며, 성인 VRoid 팩에서는 남성 티셔츠로 시험할 수 있어요. 다른 옷·원래 옷·잠옷으로 바꾸면 숨겨지고 다시 티셔츠를 입으면 나타나요. 앞뒤 중 한 면에 그림 하나를 적용하며, 새 소매·핏 등 입체 형태 편집은 아직 지원하지 않아요.

- 새 입체 의상 로컬 시제품: 개발 서버의 `/prototypes/atelier.html`에서 OFF DUTY, CITY CLUB, 남성용 TAILOR, 여성용 MAISON·AURELIA·ECLIPSE·COZY·RUE 세트와 NOCTURNE 런웨이 드레스를 실제 캐릭터에 피팅해요. 각 생성 명령은 [시제품 안내](prototypes/README.md)에 있어요. 게임·계정 저장과 분리되어 있고 배포 빌드에는 포함되지 않아요.
