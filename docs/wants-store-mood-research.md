# 바람 · 보상 상점 · 기분 조사 (2026-11-01)

상태: 2026-11-01 바람, 보상 상점, 욕구 효과를 구현했다(결과는 맨 아래 §7). 기분 효과는 `docs/mood-moodlets.md`. 3D 표현과 기분 전염은 아직이다. 아래는 구현 전 조사 내용이다. 측정은 자유 의지를 켠 2인 가족(한 명 직장인), 게임 시간 10일 × 6회, 플레이어 조작 없음이다. 실제 플레이에서는 달라질 수 있다. 제안의 수치는 시작값이다.

## 1. 바람의 현재 기준 (`src/game/wants.ts`)

한 시간마다 빈 칸(최대 3칸)을 채운다.

1. 후보를 모은다.
   - 욕구: 해당 욕구가 50 미만
   - 스킬: 10레벨 미만인 스킬 전부 (플레이어의 흥미와 무관)
   - 직업: 오늘의 과제, 승진, 일에 부족한 스킬
   - 특성: 10개 특성만 고정 바람 1개
   - 관계: **같이 사는 가족만** 대상 (친구·연인 이웃은 후보 아님)
   - 손님: 집에 와 있는 손님
2. 칸마다 묶음을 하나 뽑는다. 같은 묶음은 한 칸만. 가중치: 욕구 10, 손님 8, 로맨스 4, 스킬·직업·연인·특성 3, 친구 2. 직전에 이룬 묶음 ×1.5, 열망의 묶음 ×3.
3. 묶음 안에서는 **완전 무작위**로 고른다.
4. 24시간이 지나면 교체하고, 이룬 바람은 하루 동안 다시 안 나온다.

### 측정

| 항목 | 값 |
|---|---|
| 새로 나온 바람 중 욕구 바람 | **36%** (특성 21, 스킬 20, 친구 16, 직업 7) |
| 가장 자주 나온 바람 | 배고픔, 방광, 위생, 에너지 순 |
| 만족 포인트 (열망 포함, 자동 플레이) | 캐릭터당 하루 약 31점 |

### 문제

- 욕구 바람은 욕구 시스템과 **이중 표시**다. 바라는 것이 아니라 생리 현상이다.
- 호불호, 두려움, 기분, 열망의 다음 목표, 나이, 시간대, 최근 사건과 연결되어 있지 않다.
- 열망 연결은 넓은 묶음에 ×3뿐이다. 34개 열망이 4개 묶음(스킬·친구·로맨스·직업)만 쓴다. "운동 열망"이라도 아무 스킬이나 나온다.
- 어떤 캐릭터든 같은 목록이다. 성격이 드러나지 않는다.

## 2. 바람 개선안

**원칙: 욕구는 몸이 필요로 하는 것, 바람은 이 사람이 원하는 것.** 욕구 묶음을 없앤다. 몸 상태는 바람의 후보를 막는 조건으로만 쓴다(기진맥진하면 운동 바람 안 나옴).

| 연결 요소 | 바람 예시 | 데이터 |
|---|---|---|
| 호불호 | 좋아하는 활동 하기, 오래 못 한 활동 다시 하기, 좋아하는 유형의 사람과 어울리기 | `likes`, `miss_*` 버프 |
| 열망 | 다음 단계에 **실제 필요한 목표** 한 걸음 (가장 강한 신호) | `milestones[].goals` |
| 두려움 | 두려움 마주하기: 거절이 두려우면 마음 전하기 | `fears`의 `face` |
| 기분 | 기분에 맞는 일. 영감 → 그림, 슬픔 → 깊은 대화, 화남 → 운동으로 풀기 | `dweller.emotion`, `moods` |
| 특성 | 전 특성으로 확대, 특성당 2~3개 | `TRAIT_WANTS` |
| 관계 | 이웃·동료 포함: 친구에게 전화, 초대, 소원해진 사람 연락, 이웃과 화해 | `relationsOf`, 관계 변화 |
| 직업 | 내일 면접·승진 직전 준비, 실수를 만회 | `workSkillsShort`, 성과 |
| 사건 | 승진 축하 받기, 이별 후 위로, 새 가구 써 보기, 아기 돌보기 | 알림이 나는 사건에 훅 |
| 나이·시간 | 아이: 놀이, 노년: 산책, 저녁: 가족 식사 | `age`, 시계 |

칸 구성은 3칸 고정으로 각각 역할을 준다.

- 1칸 "꿈": 열망의 다음 걸음 (열망이 없으면 호불호)
- 1칸 "나다운 것": 호불호·특성·두려움
- 1칸 "지금": 기분·사건·손님

보상도 차등을 둔다. 쉬운 것 25, 나다운 것 50, 도전 75~150. 호불호와 열망 바람은 이루면 `wantFulfilled`와 함께 해당 행복 버프도 준다. 제목 옆에 이유를 짧게 쓴다("요리를 좋아해서").

## 3. 보상 상점

현재 물약 4종(200점)과 욕구 특성 5종(2,000~4,000점)뿐이다.

| 측정·사실 | 값 |
|---|---|
| 물약 1개 | 자동 플레이 기준 약 6.5일치 포인트 |
| 가장 비싼 특성 4,000점 | 약 129일치. 어른 기간은 보통 70일 |
| 특성 5종의 내용 | 모두 욕구 감소 (강철 방광 등) |

### 문제

- 비싼 물건은 수명 안에 살 수 없다. 플레이어 조작으로 얼마나 빨라지는지는 측정하지 못했다.
- 욕구를 줄이는 특성은 바람·기분과 무관하고, 게임을 편하게만 만든다.
- 모두 혼자 쓰는 효과이고 가격 외에 선택의 이유가 없다.
- 패널 안 목록 하나로, 가격·보유 외 정보가 없다.

### 개선안

탭 4개로 나눈다.

| 탭 | 예 | 가격 제안 |
|---|---|---|
| 기분 | 기분 전환 물약 7종, 나쁜 기분 씻어 내기 | 100~200 |
| 마음 | 바람 고정 슬롯, 두려움 극복 도움, 호불호 바꾸기, 거절 재시도 간격 짧게 | 300~800 |
| 삶 | 일 잘 풀리는 날, 스킬 집중의 날(하루 ×1.5), 관계 회복 편지, 특별 가구·옷 | 500~1,200 |
| 평생 특성 | 지금의 욕구 특성은 유지. 감정 특성 추가: 긍정 기분 오래 감, 나쁜 기분 빨리 풀림 | 1,500~3,000 |

가격은 하루 수입 기준으로 다시 맞춘다. 바람 개선 후 포인트 수입을 재서 정한다. 목표: 소모품 2~4일, 평생 특성 30~50일.

## 4. 기분의 현재 상태

구조는 참고 게임와 같다. 무드렛 가중치 합으로 15개 감정 중 하나와 세기를 정한다(`emotions.ts`, 무드렛 약 300종). 측정한 시간 비율: 불편 31%, 장난 20%, 행복·영감 각 11%, 무난 10%, 활기 9%, 자신감 5%. 긍정 55%, 부정 35%. 집이나 생활 환경에 따라 달라질 수 있다.

### 실제로 영향을 주는 곳

| 영역 | 영향 | 코드 |
|---|---|---|
| 스킬 획득 | 감정·세기별 ×0.4~×1.8 (참고 게임 데이터 그대로) | `skillGainMultiplier` |
| 자율 행동 | 감정 맞는 활동 ×1.4. 욕구 추구 배율(슬픔 위생 ×0.25 등) | `autonomy.ts` |
| 전용 행동 | 일부 행동이 특정 감정에서만 메뉴에 나옴. 카탈로그 기준 9곳 | `moods` |
| 대화 성공 | 카테고리별 점수. 로맨스 상대 화남 -20, 친근 말 건 쪽 행복 +5 등 | `contextScore` |
| 근무 성과 | 긍정 +5~20, 이상 감정 추가, 부정 -4~-12 | `shiftPerformance` |
| 업무 성공률 | 부정 -12%, 이상 감정·집중 +5% | `workSuccess` |
| 힘든 날 | 부정 +10% | `hardDayChance` |
| 사망 | 최고 세기 분노·웃음·창피가 오래가면 위험 | `DEADLY_MOODS` |
| 표정 | 웃음·찌푸림·무표정 3가지 | `expressionOf` |

### 측정: 스킬 3, 필요 3, 이상 감정이 집중인 직업

| 감정 | 업무 성공률 | 근무 성과 (+/-) |
|---|---|---|
| 집중 (이상) | 85% | +35 |
| 행복 등 긍정 | 80% | +25 |
| 무난 | 80% | +15 |
| 슬픔·화남·지루함·멍함·스트레스 | 모두 68% | +15, -4 |

### 부족한 점

1. **결과가 보이지 않는다.** 패널에는 감정 이름과 원인만 있고 "그래서 뭐가 달라지는지"가 없다. 이 효과 대부분은 플레이어가 알 수 없다.
2. **부정 감정이 모두 같다.** 슬픔과 화남이 일에 똑같이 작용하고, 화나도 일상은 달라지지 않는다.
3. **참고 게임의 가상 스킬 보정(ESM)이 없다.** 문서 P2에 남아 있다. 스킬 획득 배율은 있지만 판정에는 없다.
4. **행동이 안 바뀐다.** 슬픈 사람이 걷는 모습, 화난 사람의 대화가 평소와 비슷하다. 표정은 세 가지뿐이다.
5. **관계에 남지 않는다.** 화내서 한 말이 관계 수치에 특별히 반영되지 않고, 가족의 기분이 서로 전염되지 않는다.
6. **생활에 영향이 적다.** 요리 품질, 수면, 다툼, 식욕 등 일상 결과가 거의 변하지 않는다.

### 5.2 기분 효과를 보이게 만들기 (요청 사항)

1. **기분 카드:** 기분 이름을 누르면 나온다. 원인(무드렛)과 지금 효과를 한 화면에.
   - 예: `😠 화남 · 🧑‍💼 고객 응대 -20% · 💬 대화 실패 시 관계 ×1.5 · 🎨 스킬 획득 ×0.8` / `추천: 샤워하기, 운동하기`
2. **행동 메뉴 힌트:** 메뉴 항목에 기분 효과 표시. "그림 그리기 ✨영감 +40%", "농담하기 ⚠화남". 자세한 수치는 툴팁.
3. **결과 알림에 이유:** "화가 나서 손님과 다퉜어요", "기분이 좋아 일이 잘 풀렸어요 (+5)".
4. **근무 결과에 기분 줄:** 결과 창에 "기분 때문에 성과 +10, 집중할 때 3건 더 성공".
5. **출근 전 예고:** 직업 탭에 "지금 기분이면 오늘 성과 -4 · 집중하면 +35". 어떻게 바꿀지 추천.
6. **3D 표현:** 표정 감정별로 늘리기(VRM happy/angry/sad/relaxed/surprised), 걸음 속도·자세 변화, 머리 위 감정 아이콘 잠깐 표시.

### 5.3 기분이 사람 사이에 번지기

같은 방 가족·동료의 강한 감정이 약한 무드렛으로 전염된다(행복 +1, 화남 → 긴장 +1). 위로하기 대화로 슬픔을 줄이고, 일터 분위기 수치에도 반영한다.

## 5-1. 욕구의 현재 영향과 제안

### 현재

욕구는 직접 효과가 거의 없고 **무드렛을 거쳐** 기분에 영향을 준다. 같은 값이어도 어떤 욕구인지에 따른 차이가 작다.

| 욕구 | 낮을 때 무드렛 (가중치) | 0이 되면 |
|---|---|---|
| 배고픔 | 25 미만 배고픔 1, 12.5 미만 굶주림 40 (불편) | 기절, 어른은 죽음으로 이어짐 |
| 에너지 | 25 미만 피곤 1, 12.5 미만 탈진 3 (불편) | 기절, 수영 중이면 익사 |
| 생리현상 | 25 미만 1, 12.5 미만 40 (불편) | 실수, 위생 0, 웅덩이 |
| 위생 | 25 미만 꾀죄죄함 1, 0.5 미만 더러움 2 (불편) | 없음 |
| 재미 | 25 미만 1, 0.5 미만 3 (스트레스) | 없음 |
| 사교 | 25 미만 외로움 1, 0.5 미만 고독 3 (슬픔) | 없음 |

그 외: 자율 행동의 긴급도, 12 미만이면 하던 일을 끊고 해결, 사교 25 미만이면 외로움 두려움, 근무에는 직접 영향 없음. 모두 높으면 행복 버프. UI는 막대와 무드렛뿐이고 효과 설명이 없다.

### 부족한 점

- **더러워도 남의 반응이 없다.** 위생은 0이어도 관계에 영향이 없다.
- **피곤해도 일을 잘한다.** 기분이 괜찮으면 업무 성공률이 그대로다.
- **위생·재미·사교는 0이 돼도 결과가 약하다.**
- **좋은 상태의 보상이 작다.** 충족 버프 하나뿐이다.
- 욕구 칸의 값과 실제 불이익의 연결이 화면에 없다.

### 제안: 욕구별 고유 결과 (기분과 겹치지 않게)

욕구 → 기분 경로는 유지하고, 기분으로 설명되지 않는 **몸의 결과**만 추가한다.

| 욕구 | 낮을 때 (25 미만 / 12 미만) | 높을 때 (80 이상) |
|---|---|---|
| 배고픔 | 집중 업무 성공 -5% / 걸음 -10%, 요리 중 사고 위험 | 운동 효율 +10% |
| 에너지 | 업무·판정 -8% / -15%, 걸음 느림, 하품, 운전 사고 | 스킬 획득 +10% |
| 생리현상 | 활동 중 끊김, 집중 -5% / 앉아 있는 활동 금지 | 없음 |
| 위생 | 상대 대화 점수 -3, 로맨스 수락 -10% / -6, -25%, 냄새 표시, 고객 응대 -10% | 첫인상 +, 로맨스 수락 +5% |
| 재미 | 일 효율 -5%, 하기 싫은 일 거부 확률 / 의무 활동 거부, 충동적 행동 | 창작 스킬 +10% |
| 사교 | 대화 시 수다 길어짐, 감정 전염 약함 / 사람을 찾아 나섬, 외로움 두려움 진행 | 관계 호감 증가 +10% |

표시 방식은 기분과 같은 효과 데이터를 공유한다. 욕구 막대에 마우스를 올리면 "지금 효과"가 나오고, 낮아질 때 **다음 구간에 무슨 일이 생기는지** 미리 알려 준다. 바람과는 겹치지 않는다(2번 원칙).

## 6. 진행 순서 제안

1. **기분·욕구 효과표 + 기분 카드 + 알림 이유 + 근무 결과** (가장 눈에 띄고 이후 작업의 토대)

3. **보상 상점 개편:** 2번 후 포인트 수입을 재서 가격 확정
