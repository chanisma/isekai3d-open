# 의상 제작·착용 작업 지식

2026-10-20 대화에서 정리한 권장 작업 순서입니다.
앞으로 캐릭터 몸체, 의상 제작, 피팅, 의상 저장 구조를 작업할 때 먼저 참고합니다.
아래 내용은 설계 방향이며, 모두 구현되었다는 뜻은 아닙니다.

## 기본 방향

**온전한 기본 몸체 + 별도 의상 파일 + 실행 중 착용**을 사용합니다.

캐릭터와 의상의 모든 조합을 각각 VRM으로 만들지 않습니다.
캐릭터 VRM에는 얼굴·헤어·몸·뼈대를 유지하고, 별도 의상 GLB를 호환되는 뼈대에 연결합니다.
의상을 갈아입을 때는 기존 의상과 피부 가림 정보를 해제하고 새 의상과 가림 정보를 적용합니다.
몸 메시 자체는 영구 삭제하지 않습니다.

## 권장 작업 순서

1. **기본 캐릭터의 몸체부터 정리합니다.**
   - `.vroid` 원본이 있으면 그 캐릭터의 피부와 몸 메시를 보존해 다시 내보내는 방식을 우선합니다.
   - 피부가 많이 보이는 복장을 선택하는 것만으로 전신 메시 보존이 보장되지는 않습니다.
   - 의상별 Skin Mask와 내보내기 시 메시 제거 여부를 확인하고, 결과 VRM의 실제 몸 메시를 검사합니다.
   - 원본을 사용할 수 없는 캐릭터는 호환되는 몸 메시로 빠진 부위를 보충합니다.
   - 보충할 때에는 체형·관절 위치·웨이트·피부색·UV와 연결부를 맞춰야 합니다.
   - 몸체를 통일한다는 것은 얼굴과 체형을 모두 같게 만든다는 뜻이 아니라, 각 캐릭터가 필요한 신체 부위를 온전히 갖추도록 한다는 뜻입니다.

2. **체형별 의상 피팅을 안정화합니다.**
   - 우선 성인 남성·여성용과 기존 OFF DUTY / CITY CLUB 세트를 검증합니다.
   - 어린이·유아는 별도 사이즈를 준비하고 청소년·노인도 실제 체형에 맞는지 확인합니다.
   - 모든 체형을 자동으로 보정하는 기능을 먼저 만드는 대신, 지원할 체형부터 순차적으로 맞춥니다.
   - 뼈 이름이 같다는 것만으로 옷 크기·스키닝·관통 문제가 해결되지는 않습니다.

3. **의상마다 신체 가림 정보를 설정합니다.**
   - 반팔·긴소매·반바지·긴 바지·신발에 서로 다른 가림 영역을 지정합니다.
   - 상의·하의·신발을 함께 입으면 각 영역을 합쳐 적용하고, 벗거나 교체하면 다시 계산합니다.
   - 의상과 몸체 사이즈에 맞춰 작은 면 단위로 지정합니다. 팔 전체 같은 큰 단위만으로 처리하면 소매 끝에서 구멍이 보일 수 있습니다.
   - 옷 경계 아래에는 여유를 남기고 서기·걷기·앉기·팔 벌리기에서 노출되는 부분이 없는지 확인합니다.
   - 면 인덱스를 저장하는 구현이라면 몸체의 토폴로지/버전과 함께 관리합니다. 다른 메시나 재내보낸 모델에 인덱스를 그대로 적용하지 않습니다.
   - 가림 정보를 해제해도 삭제된 피부 메시가 생기지는 않습니다. 1단계의 몸체 보존/복원이 선행되어야 합니다.

4. **저장은 조합 정보 중심으로 설계합니다.**
   - 캐릭터 ID + 부위별 의상 ID + 색상 + 프린트 참조/설정을 저장합니다.
   - 공용 의상 파일은 재사용하고, 캐릭터마다 동일한 의상 바이너리를 중복 저장하지 않습니다.
   - 프린트 이미지 등 실제 에셋의 저장·참조 방식은 조합 정보와 함께 설계해야 합니다.
   - 착용 결과를 합친 VRM 내보내기는 외부 프로그램에서 사용할 필요가 생겼을 때 추가합니다.

현재 우선순위는 **새 의상을 계속 늘리는 것보다 기본 몸체를 정리하고 기존 두 세트의 착용 품질을 안정화하는 것**입니다.

## 의상별 가림 정보의 예

| 의상 | 숨길 수 있는 피부 영역 | 경계 확인 |
| --- | --- | --- |
| 반팔 티셔츠 | 몸통과 소매 안쪽의 어깨·팔 윗부분 | 목·소매 끝·밑단 |
| 바시티 재킷 | 몸통과 소매에 덮이는 팔 | 목·손목·여밈·밑단 |
| 반바지 | 골반과 덮이는 허벅지 | 허리·바짓단 |
| 긴 바지 | 골반부터 바지 밑단까지 | 허리·발목 |
| 신발 | 신발 안에 들어가는 발 부분 | 발등·발목 입구 |

이는 설계 예시입니다. 실제 의상 모양과 체형에 맞춰 지정해야 하며, 피부 가림만으로 옷의 크기나 찢어진 봉제선까지 고쳐지지는 않습니다.

## 문제를 구분하는 기준

| 증상/상태 | 확인 및 대응 |
| --- | --- |
| 몸 메시가 있고 피부만 투명함 | 마스크·피부 텍스처·재질 확인 |
| 몸의 특정 부위 메시 자체가 없음 | 원본에서 재내보내기 또는 몸 메시 보충 |
| 몸판과 소매 사이가 벌어짐 | 의상 연결 정점의 좌표·웨이트 확인 |
| 몸이 옷을 뚫고 나옴 | 체형별 의상 형상·웨이트 보정과 피부 가림 조정 |
| 로딩과 렌더링이 성공함 | 착용 품질 통과로 간주하지 말고 관통·누락·비율을 따로 검사 |

실제 확인 사례:

- 성인 태오는 원래 옷에 가려지는 팔 피부 메시 일부가 없고, 성인 우진은 해당 영역이 남아 있어 OFF DUTY 반팔 착용 결과가 달랐습니다.
- CITY CLUB은 몸판만 축소하면서 소매 연결부가 최대 약 19.56mm 벌어졌습니다. 암홀의 원래 좌표·웨이트를 유지하고 그 아래 몸판만 축소하도록 수정했습니다.
- 연결부는 정지 화면뿐 아니라 애니메이션 중에도 확인합니다. 두 패널의 같은 위치 정점이 서로 다른 웨이트를 갖고 있으면 움직일 때 다시 벌어질 수 있습니다.

## 현재 구현과 미구현 구분

- (2026-10-23) 성인 10명의 기본 몸(`@base`, 속옷 차림)을 `.vroid` 원본에서 다시 내보냈고, 게임과 시제품 화면이 그 몸에 기존 옷을 떼어 다시 입혀요. 의상별 피부 가림은 옷 파일이 잘라낸 몸에서 자동으로 구해요(`bodyMask.ts`, `wearOnBase`). 자세한 것은 [캐릭터 목록 §7](02-cast.md).

- (2026-10-24) 기본 몸이 있는 캐릭터의 파일은 옷만 저장해요(`models/compare/clothes.py`, 가림 정보를 파일에 함께 저장). 위 4번 '공용 의상 파일은 재사용'의 첫 단계예요. 다른 나이의 기본 몸은 만드는 중이에요.

- 로컬 피팅 화면은 실제 캐릭터에 의상을 이식하고, 기존 의상을 숨겨 비교할 수 있습니다.
- 일반 의상 교체 코드 `src/view3d/vrmDress.ts`에는 몸 메시 보충 처리가 있지만, 임의의 체형을 완벽히 자동 복원하는 기능은 아닙니다.
- OFF DUTY / CITY CLUB / MAISON 로컬 피팅에는 몸 메시 보충 처리를 연결하지 않았습니다. NOCTURNE 드레스는 성인 여성에 한해 노출 상체·팔 메시 보충과 피부 텍스처 보충을 연결했습니다. COZY 미니스커트는 성인 여성의 노출 허벅지 피부 메시·텍스처를 보충합니다. 두 처리는 로컬 피팅에만 연결되어 있습니다.
- 범용 의상별 신체 가림 전환 체계는 미구현입니다. NOCTURNE에는 성인 여성 bind 좌표 기준 중앙 몸통·골반·다리 가림을 시범 적용했습니다. 로컬 인스턴스에만 적용하고 의상 변경 시 원본을 다시 읽어 해제합니다. 가림은 관통 피부를 숨기지만, 앉을 때 긴 치마가 접히는 문제는 해결하지 않습니다.
- 선택한 캐릭터의 착용 결과를 합친 새 VRM 내보내기는 아직 구현되어 있지 않습니다.
- 생성된 착용 VRM은 제작 기준 캐릭터용입니다. 의상 GLB가 모든 VRM에 자동으로 맞는 것은 아닙니다.
- 현재 의상 시제품 작업은 로컬 범위입니다. 이 문서의 저장 설계가 DB 업로드나 라이브 반영을 승인하는 것은 아닙니다.

## 피팅 대상 선정 — 2026-10-23 보완

- 새 성인 여성 의상은 기본 다인·하나·미나·서아 4명부터 검사합니다.
- 새 성인 남성 의상은 기본 지호·준호·태오·우진 4명부터 검사합니다. TAILOR는 긴소매·긴 바지 기준으로 이 4명을 검사했습니다.
- 같은 체형의 복장 변형·중복 NPC를 매번 전수 검사하지 않습니다.
- 노출 의상은 피부 메시 누락 등 해당 의상에 필요한 예외 모델만 추가합니다. RUE는 다인 bathing 1개를 추가해 5개를 검사했습니다.
- 전체 검사는 공용 착용 로직 변경이나 광범위한 회귀 우려가 있을 때 실행합니다.
- RUE는 짧은 흰 양말과 미니 사이에 드러나는 다리 피부를 보충합니다. COZY의 허벅지 보충 함수에 하한을 지정하며, COZY의 기존 기본값은 유지합니다.

## 공용 의상의 성별·연령 사이즈 — ROBE 01

공용은 디자인 공유를 뜻하며 성인 메시 하나를 모든 연령에 이식한다는 뜻이 아닙니다.
남녀 × 유아·아동·청소년·성인·노년 10개 뼈대 기준 파일을 만들고, 모델 파일의 성별·연령으로
자동 선택합니다. ROBE는 관절별 rest 공간 변환으로 위치와 팔 길이를 조정하고 목 높이에 비례해
두께를 조절했습니다. 같은 분류 안에서 개인별 둘레를 측정하는 자동 맞춤은 아직 없습니다.

공용 의상 피팅은 각 사이즈의 대표 1명씩과 성인 기본 남녀 8명을 포함해 16명으로 시작합니다.
중복 복장/NPC 전체 검사는 하지 않습니다. 피부 마스크는 사이즈 비례 좌표를 사용하고 해당 의상에만
적용합니다. 가운 앞자락의 허벅지 가중치는 앉기 보정용이며 천 시뮬레이션을 대신하지 않습니다.

## 직업복 디테일 검수 — 2026-10-25

- 직업 → 실제 업무 역할 → 복장 구성 → 직급 장식 순서로 나눕니다. 다른 현장 업무를 색만 바꾼 공통 유니폼으로 처리하지 않습니다. 실제 같은 복장을 쓰는 역할의 패턴 공유는 유지합니다.
- 전신 연락판만으로 칼라·여밈 품질을 판정하지 않습니다. 상체 확대 및 사선 시점에서 겹친 원단, 연결부, 주머니 덮개와 앞섶의 높이 순서를 확인합니다. 조끼 위 파우치·앞치마 위 포켓은 바탕 의상 표면보다 해당 겉감 두께만큼 더 앞에 있어야 합니다.
- 장식의 웨이트는 가까운 정점 몇 개보다 원단 표면 삼각형의 무게중심 좌표를 우선 사용합니다. 열린 V넥을 향한 투영이 등판을 맞힐 수 있으므로 앞면 교차인지 검사하고, 빈 목 부분은 실제 앞섶 경계 사이를 연결합니다.
- 칼라의 목 연결점은 목의 깊이에 둡니다. 목 위 모서리를 가슴 깊이에 투영하면 칼라가 수직으로 솟거나 뜹니다. 목 안단은 몸판과 동일한 원단·염색 규칙을 사용합니다.
- VRM의 MToon 외곽선 재질을 그대로 불투명 PBR로 변환하면 원래 색의 외곽선 패스가 염색 원단을 덮습니다. 로컬 PBR 검수에서는 외곽선 패스를 제외합니다.
- 유한 정점, 가중치 합, 파일 용량 검사와 시각적 착용 검수는 별개입니다. 자동 검사 통과를 관통·들뜸이 없는 최종 품질로 표현하지 않습니다.

구현 및 역할 목록: [직업복 컬렉션](../../prototypes/CAREER-COLLECTION.md).

## 목선·신체 가림·앉기 검수 — 2026-10-25

- 기존 옷의 가림 마스크를 새 의상에 무조건 복사하지 않습니다. 닫힌 원단 안쪽의 몸통·골반·소매는 가리되 목, 손, 발목, 열린 밑단과 트임 안에서 보일 다리는 유지합니다. 원본 소매보다 옷을 좁혔다면 공간 포함 검사만으로 판단하지 않습니다. 이때 피부가 옷 밖에 있으므로 원본 소매 가림과 실제 피팅을 함께 확인해야 합니다.
- 원본 칼라와 새 칼라를 중복 남기지 않습니다. 라펠 속 셔츠 칼라처럼 의도한 겹침만 유지합니다. 목 안단·지퍼·넥타이를 가슴 표면 깊이에 투영하면 목 앞에 떠 보입니다. 칼라 아래에 위치하도록 목 깊이와 원단 순서를 함께 설정합니다.
- 앉기 검수는 전환 완료 뒤 정면·측면·낮은 뒤 시점에서 진행하고 다시 일어서기도 확인합니다. 20프레임만 진행한 캡처는 앉기 전환 중간일 수 있습니다. 현재 로컬 검수는 3초를 진행합니다.
- 짧은 치마부터 긴 드레스까지 동일한 강체 회전을 쓰지 않습니다. 앞판은 허벅지 위를 따라 무릎까지 이동한 뒤 아래로 내려오고, 뒤판은 엉덩이를 먼저 감싼 뒤 허벅지 아래로 이어져야 합니다. 뒤판 전체를 바로 무릎 방향으로 옮기면 골반이 노출됩니다. 의자 전체를 피하도록 밑단 반경을 늘리면 풍선처럼 부풀어 오릅니다.
- **앉는 자세 수정은 여성만 적용합니다.** 여성의 치마류에는 선택적으로 `legs: 'together'` 자세를 사용하고 남성은 기존 자세를 유지합니다. 의상 들뜸 보정과 신체 가림은 남녀 모두 검토합니다. 일반 복장과 목욕 자세에는 자동 적용하지 않습니다. 공용 샤워가운은 연령별 크기에 맞춰 검수 의자 높이도 조정합니다.
- `src/dev/skirtSkin.ts`, `skirtDrape.ts`, `gownDrape.ts`는 로컬 피팅 전용입니다. 신체 파일과 DB를 수정하지 않으며, 자세 보정은 의상 GLB 자체에 포함되지 않습니다. 일반 천·의자 충돌 솔버를 대신하지 않습니다.
